# Assembly Asteroids Game
Asteroids game made in a simplified version of Assembly for my Systems 1 course. Objective is to shoot lasers at the falling rocks. If a rock hits the spaceship, the game is over.
# Controls:
Press A to move left
Press D to move right
Press W to shoot laser
# How to run:
Paste the code on the Assembly emulator found here: https://github.com/drb0r1s/assembly-reality
